- 修复更新弹窗触发的崩溃：No ActivityResultRegistryOwner was provided via LocalActivityResultRegistryOwner。
  - 做了什么：在 ProvideLocalizedContext 中，除既有的 LocalActivity 外，显式提供 LocalActivityResultRegistryOwner（取自宿主 Activity），与本地化 Context 一并注入组成，使 Activity Result 类能力在本地化后仍可用。
  - 踩坑：现象→原因→解法：
    - 现象：真机（Xiaomi 2211133C / Android 15）在组合阶段（帧回调内）崩溃，异常为 java.lang.IllegalStateException: No ActivityResultRegistryOwner was provided via LocalActivityResultRegistryOwner；触发点是新增更新弹窗里的 rememberLauncherForActivityResult 首次组合。
    - 原因：解包 activity-compose 1.13.0 的 classes.jar 用 javap 核对，并比对官方源码，LocalActivityResultRegistryOwner.current = LocalComposition.current ?: findOwner&lt;ActivityResultRegistryOwner&gt;(LocalContext.current)，即只沿 LocalContext 链查找；本项目 ProvideLocalizedContext 用基于 Application 的本地化 Context 替换 LocalContext，链上取不到宿主 Activity，故为 null 并抛错。同一原因能解释 BackHandler 为何未崩：LocalOnBackPressedDispatcherOwner.current 多了一层 LocalView.current.findViewTreeOnBackPressedDispatcherOwner() 视图树回退。
    - 解法：沿用既有 LocalActivity 补丁思路，显式把宿主 Activity 作为 LocalActivityResultRegistryOwner 提供；未改为"基于 Activity 创建本地化 Context"，以免破坏 LocalizationManager 的应用级单例定位。
