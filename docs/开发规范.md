当与其它规则冲突时按本规则执行

# 准则

## 架构与职责
 职责相同则内聚，职责相异则解耦；同一职责不得四散，一个功能需翻阅多个文件、甚至跨层文件才能拼出全貌，即不符合预期。
 子目录采用语义命名，父目录采用泛义命名：父目录表示这里可能有什么，子目录则明确是什么。

## 依赖注入
 依赖注入不使用 Hilt 或 Koin，手动 DI 更清晰。

## UI 与布局
 布局组件原子化，统一置于 ui/component/，不做“共享/私有”下沉判断。
 页面级组装单元（承载页面状态与副作用的组合件，如内容单元）与页面专用弹窗按语义收敛于页面包内子目录（如 content/、dialog/），不直接平铺在页面包根；仅纯原子布局组件统一置于 ui/component/。
 根据旋转状态、功能模式、窗口尺寸类（Compact/Expanded）选择对应组装器；“XxxScreen”只做分发与跨形态副作用，不写布局。

## 性能与并发
 缓存昂贵计算结果并提供稳定唯一键；状态管理遵循官方最佳实践。
 耗时任务采用协程 + 结构化并发切离主线程；可并行任务充分并发，避免串行和阻塞主 UI。

## 平台与 API
 平台/框架 API 一律查官方一手来源后再写，禁止凭记忆使用已废弃或已移除的接口。

## 日志与崩溃
 仅记录失败（异常与崩溃）；成功路径不输出日志。

页面目录结构示例:
```text
screens/settings/
├── compact/
│   └── SettingsCompactAssembly.kt   # 窄屏组装器
├── expanded/
│   └── SettingsExpandedAssembly.kt # 宽屏组装器
├── content/
│   └── SettingsContent.kt           # 页面级组装单元（承载页面状态/副作用，可选）
├── dialog/
│   └── ThemeSelectionDialog.kt       # 页面专用弹窗（可选）
├── dialog/
│   └── LanguageSelectionDialog.kt    # 页面专用弹窗（可选）
├── SettingsScreen.kt                    # 只做形态分发，不写布局
├── SettingsUiState.kt                   # 页面级 UI 状态（可选）
└── SettingsViewModel.kt                 # 页面级 ViewModel（可选）
```

顶层目录结构示例:
```text
com/template/evilgodxu/
├── data/              # 数据层
├── log/               # 异常日志与崩溃采集
├── navigation/        # 导航宿主与路由定义
├── floatingwindow/    # 悬浮窗(按需创建)
├── worker/            # 后台任务(WorkManager,按需创建)
├── screens/           # 页面层：XxxScreen + ViewModel + UiState + 形态组装器
├── theme/             # 主题：颜色、字体、整体主题(独立功能创建顶层目录不归于UI大类)
├── localization/      # 语言本地化管理
├── windowSize/        # 窗口尺寸类判定
├── ui/                # 跨页面复用组件与通用 UI 能力
│   ├── component/     # 原子化布局组件（统一放置，不做共享/私有下沉）
│   ├── dialog/        # 通用对话框(属于独立类型故不放入 component)
│   ├── popupwindow/   # 浮动窗口(属于独立类型故不放入 component)
│   ├── sheet/         # 抽屉面板(BottomSheet 等,独立类型故不放入 component)
│   ├── toolbar/       # 工具栏(独立类型故不放入 component)
│   ├── toast/         # 轻提示(Snackbar/Toast,独立类型故不放入 component)
│   └── icons/         # 图标资源封装
├── update/            # 应用更新检查与下载
├── utils/             # 通用工具
├── App.kt                    # Application 入口
├── AppContainer.kt           # 手动 DI 容器（应用级单例）
├── AppUiState.kt             # 应用级 UI 状态聚合（主题/语言/版本）
├── MainActivity.kt           # 唯一 Activity
└── MainViewModel.kt          # Activity 专属 ViewModel
```

在不违反上述规范的情况下遵循官方推荐做法与社区最佳实践。
